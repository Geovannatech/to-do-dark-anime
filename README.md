# 📝 To-Do Dark Anime

Projeto simples de To-Do List feito com HTML, CSS e JavaScript.

## 🚀 Tecnologias
- HTML5
- CSS3
- JavaScript

## ✨ Funcionalidades
- Adicionar tarefas
- Marcar como concluídas
- Tema dark com estilo anime

## 🎨 Design
- Dark mode
- Fonte Fraktur
- Visual moderno e estilizado

## 📌 Objetivo
Projeto de estudo e prática em Front-End para portfólio.
